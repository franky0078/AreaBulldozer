# Area Bulldozer

Area Bulldozer adds a convenient area deletion tool to Cities: Skylines II.

Instead of removing objects one by one, you can select a larger area using either a circular or square selection. The size of the selected area can be adjusted directly in the tool interface.

## Features

* Delete multiple objects within a selected area
* Circular and square selection modes
* Adjustable selection size
* Object filters for more precise deletion
* Optional background darkening for better visibility
* Visual highlighting of activity and spawn markers
* Compact in-game user interface
* Movable tool button
* Configurable keyboard shortcut
* English and German localization

## How to use

1. Activate the Area Bulldozer tool using the toolbar button or the configured keyboard shortcut.
2. Select either the circular or square deletion mode.
3. Adjust the size of the selection area.
4. Enable or disable the desired object filters.
5. Move the selection over the area you want to clear.
6. Confirm the deletion using the left mouse button.

Please check the selected filters carefully before deleting objects from your city.

## Compatibility

Area Bulldozer is an independent mod and may be used alongside other bulldozer or deletion-related mods. However, using multiple deletion tools at the same time may cause unexpected behavior.
